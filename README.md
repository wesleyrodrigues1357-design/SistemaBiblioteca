# Sistema de Biblioteca

## Status do Projeto
Em desenvolvimento.

## Tecnologias Aplicadas
- Java
- Java Swing
- NetBeans
- MySQL
- Git
- GitHub

## Time de Desenvolvedores
- Wesley Rodrigues

## Objetivo do Software
Desenvolver um sistema desktop para gerenciamento de biblioteca, permitindo o cadastro de livros, usuários, empréstimos e devoluções.

## Funcionalidades do Sistema
- Login de usuário
- Cadastro de livros
- Cadastro de usuários
- Registro de empréstimos
- Registro de devoluções
- Navegação entre telas
- Integração com banco de dados MySQL
